Project Gallery

Catalogue & Search View

Users can browse books, filter by genre, sort by title, author and year, and execute real-time searches against the local SQLite database.

Personalized Recommendations

The recommendations tab provides book suggestions based on the user's previously read genres and authors.

Current Loans

Users can monitor active loans, tracking issue dates, due dates, and real-time return statuses.

Loan History

Past book loans are logged alongside official return timestamps.

Admin Management Panel

Administrators have a dedicated control center to oversee inventory, edit user roles and information, add and update book copies, and manage active loans.

Account Settings

Users can maintain their profile details by updating their passwords, phone numbers, and email addresses.
